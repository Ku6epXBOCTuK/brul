# Язык скрипта

Статус: draft. Канон языка: парсер и интерпретатор проверяются на этой спеке,
примеры в конце — фикстуры тестов.

Принципы — [ограничения DSL](../dev/architecture.md#ограничения-dsl).

## Идея

```js
let domain = currentUrl();
if (remembered[domain]) {
  launch(remembered[domain]);
}
```

Динамическая типизация, четыре вида значений, исполнение — интерпретатор AST на
UI-потоке. Скрипт оперирует **свойствами компонента**: чтение — чтение сигнала,
присваивание — запись сигнала (обновления UI точечные, через brul-reactive).

## Значения и типы

| Тип    | Литералы                          | Примечание                                |
| ------ | --------------------------------- | ----------------------------------------- |
| Number | `42`, `3.14`, `-1`                | f64 внутри интерпретатора                 |
| String | `"текст"`, `` `шаблон ${expr}` `` | шаблоны-строки MVP — да (нужны для Text)  |
| Bool   | `true`, `false`                   |                                           |
| Null   | `null`                            | отсутствие значения (пустой Image и т.п.) |

Составные: **массивы** `[a, b, c]` и **объекты** `{ name: "Chrome", flags: "" }`
(нужны для моделей `each` и конфигураций). Обращение: `item.name`, `arr[0]`,
`len(arr)` — см. встроенные функции.

Типы не объявляются; свойство компонента типизировано в разметке
(`prop checked: Bool`) — интерпретатор проверяет тип при записи.

## Лексика

- Комментарии: `//` до конца строки.
- Идентификаторы: `camelCase`.
- Точка с запятой **обязательна** в конце инструкции. ASI (авто-вставка)
  отсутствует.
- Ключевые слова: `let`, `const`, `if`, `else`, `function`, `true`, `false`,
  `null`, `import`, `from`.

## Грамматика (EBNF)

Выражения общие с разметкой; точка входа из разметки — `Expr`. Приоритет — от
слабого к сильному.

```ebnf
{{#include script.ebnf}}
```

- `+` — сложение чисел; для строк — конкатенация; смешанные типы — **ошибка**
  (явные преобразования через встроенные функции, никакого JS-автокастинга).
- Присваивание валидно только на: свойство компонента (`checked = ...`),
  переменную (`let`/`const`), элемент массива/объекта.
- Импорты допустимы только в начале скрипт-блока.
  `import BrowserItem from "./browser_item";` — имя становится доступно разметке
  как компонент.
- Функции — только на верхнем уровне скрипт-блока, без вложенности (MVP).
- Неопределённая переменная/свойство/функция — **ошибка компиляции** с позицией
  (все имена резолвятся статически: пропсы компонента, локальные `let`, функции,
  импорты, встроенные функции).

## Семантика выполнения

- **Контекст:** скрипт-блок компонента выполняется один раз при создании
  компонента (инициализация `let`-переменных и начальных значений); обработчики
  и функции — при событии/вызове, с доступом ко всем именам компонента.
- **Переменные:** `let` допускает повторное присваивание, `const` — нет
  (повторная запись — ошибка компиляции). `const` требует инициализатор:
  `const x;` — ошибка компиляции.
- **Функции:** только верхний уровень, без замыканий в MVP. Тело исполняется в
  контексте компонента. Параметры — динамические значения без типов; тип
  проверяется при присваивании свойству. Рекурсия допустима. Функции доступны
  разметке как обработчики; вызов функций из _выражений_ разметки — вне MVP
  (только встроенные функции).
- **Свойства = сигналы:** чтение внутри выражения разметки создаёт зависимость
  (трекинг brul-reactive); присваивание — запись сигнала и точечное обновление
  UI. Чтение внутри обработчика — без трекинга.
- **Приведение при записи:** только точные совпадения типов; несовпадение —
  ошибка исполнения с позицией. `Number` из `String` — только через `Number(x)`
  явно.
- **Ошибки исполнения** (индекс вне массива, тип, деление на ноль): обработчик
  прерывается, ошибка логируется с позицией, приложение не падает.
- **Поток:** весь скрипт — на UI-потоке. Долгие операции — на Rust-стороне
  (tokio), скрипт получает результат через сигнал; обещания — v3+.
- **Таймеры:** `every(ms, fn)` вызывает функцию раз в `ms` миллисекунд на
  UI-потоке, в контексте компонента; первый вызов — через `ms`. `fn` — имя
  функции верхнего уровня, как у обработчиков; функции-как-значения остаются вне
  MVP. Таймер живёт вместе с компонентом и останавливается при его удалении;
  отмены в MVP нет.

## Встроенные функции (MVP)

| Функция                  | Назначение                                                             |
| ------------------------ | ---------------------------------------------------------------------- |
| `String(x)`, `Number(x)` | явные преобразования                                                   |
| `len(arr)`               | длина массива                                                          |
| `set_theme(name)`        | переключение темы (см. style.md)                                       |
| `exit()`                 | закрыть окно/приложение (в окне)                                       |
| `every(ms, fn)`          | повторяющийся вызов функции раз в `ms` миллисекунд                     |
| _хост-функции_           | регистрируются приложением с Rust-стороны (`launch_browser(i)` и т.п.) |

Набор минимален; хост расширяет его без изменения языка.

## Таблица «конструкция → статус»

| Конструкция                                                                                                | Статус                                  |
| ---------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| `let`/`const`, литералы, операторы, тернарник, вызовы, `if/else`, массивы, объекты, шаблоны-строки, импорт | **MVP**                                 |
| Объявления функций верхнего уровня (`function`)                                                            | **MVP**                                 |
| `for`/`while` в скрипте                                                                                    | v3+ (повторение UI — `each` в разметке) |
| Замыкания, вложенные функции, функции-как-значения                                                         | v3+                                     |
| `try`/`catch`                                                                                              | v3+                                     |
| `async`/`await`                                                                                            | v3+ (обещания)                          |
| Классы, `this`, прототипы, `new`                                                                           | никогда                                 |
| `var`, ASI, неявные приведения, `==` с приведением типов (`==` строгий)                                    | никогда                                 |
| Методы массивов (`map`/`filter`/...)                                                                       | v3+ по потребности                      |
| Модули-экспорты (`export`)                                                                                 | v3+ (сейчас — один компонент на файл)   |

Детали, зафиксированные как норма:

- Изменение моделей — присваиванием нового массива свойству
  (`browsers = [...]`); методов `push`/`pop` нет.
- `{` в позиции инструкции — блок (правило JS); объектный литерал в позиции
  инструкции — ошибка компиляции.
- Запись по индексу `arr[i] = x` разрешена.
- Идентификаторы — только `camelCase`: `-` невозможен (конфликт с вычитанием).
  Данные конфига читаются строковым индексом без преобразований:
  `settings["always-ask"]`, `browser["profile-dir"]`.

## Тест-примеры (покрывают грамматику)

### 1. Скрипт компонента пикера

```script
import BrowserItem from "./browser_item";
import Footer from "./footer";

let browsers = loadBrowsers();
let remembered = loadRemembered();
let currentUrl = "";
let selectedIndex = 0;

if (len(browsers) > 0) {
  selectedIndex = 0;
}

// вызывается из разметки: on clicked(i): launch
function launch(i) {
  let browser = browsers[i];
  openWith(browser.path, browser.flags);
}
```

### 2. Обработчики (только именованные функции, инлайнов нет)

```script
function handleKey(ev) {
  if (ev.code == "Escape") {
    exit();
  }
}
```

Присоединение в разметке окна: `on key: handleKey`; проверка кода клавиши — в
скрипте, без спец-грамматики под отдельные клавиши.

### 3. Выражения разметки (те же выражения, другой потребитель)

```script,ignore
Text (url-text) { currentUrl }
Text (count) { `Выбрано: ${selectedIndex + 1} из ${len(browsers)}` }
Image (check-icon, visible: selected) { checkSvg }
View (item-panel, selected: i == selectedIndex) { }
```

### 4. Таймер обновления статусов

```script
function refresh() {
  reloadServices();
}

every(3000, refresh);
```

`reloadServices` — хост-функция панели служб: запускает чтение статусов на
Rust-стороне, результат приходит в свойство `services`.
