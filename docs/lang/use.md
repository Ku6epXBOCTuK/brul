# Язык импортов

Статус: stable. Канон языка: парсер импортов проверяется на этой спеке.

Принципы — [architecture.md §Решения](../dev/architecture.md#решения).

## Идея

Компонент переиспользуется, когда его файл объявлен в блоке `<use>`. Импорт —
декларация файла, а не инструкция скрипта: имя становится доступно разметке как
компонент.

Блок `<use>` — часть структуры SFC, см. [markup.md](markup.md) §«Файлы и
импорты».

## Грамматика (EBNF)

```ebnf
{{#include use.ebnf}}
```

## Семантика

- Форма одна: `import Name from "./path";` — другого синтаксиса импорта нет.
- Путь относителен файла, в котором стоит `<use>`; расширение `.brul`
  подставляется, если его не указали.
- Имя из `<use>` доступно разметке как компонент; инструкцией скрипта импорт не
  является.
- Найденный файл разбирается целиком, его собственные `<use>` дают цепочку; цикл
  — ошибка загрузки с путём цепочки.
