# План

Маршрут срезами: один срез — один коммит и один ревью. Процесс и бюджет среза —
[workflow.md](workflow.md); здесь только очередь. Срез закрыт, когда зелёные
`cargo clippy --workspace -- -D warnings` и `cargo test --workspace`; закрытая
строка удаляется из файла, историю хранит git. Текущий срез — задача в трекере
`BRUL`.

## Фаза 2 — рендер без DSL

- 2.1 — конфиг пикера: TOML (browsers, path, args, default, правила доменов,
  remembered), `resolve(url)`; зависимости `toml` и `serde`.
- 2.2 — запуск браузера: `Launcher` для Windows/macOS/Linux без shell,
  подменяемый runner для тестов.
- 2.3 — окно пикера, статика: 488×800, хедер с URL, список с иконками и
  default-badge, футер, тема при старте.
- 2.4 — выбор и чекбоксы: hover/selected, клик по строке, remember/always ask,
  Esc, callback без запуска.
- 2.5 — темы и живой сценарий: `system|dark|light` из конфига, следование
  системной теме, ручной выбор, запуск реальной ссылки.

Готово, когда: пикер открывает реальные ссылки без DSL.

## Фаза 3 — DSL

- 3.1 — парсер разметки по [markup.md](../lang/markup.md), ошибки с позицией.
- 3.2 — парсер стилей → снапшоты, валидация свойств и тем.
- 3.3 — парсер скрипта + интерпретатор.
- 3.4 — кодеген `.brul` → Rust: дерево виджетов и update-функции.
- 3.5 — интеграция: компонент из спеки работает в окне.

Готово, когда: путь `.brul` → код → экран пройден.

## Фаза 4 — MVP

bropicker:

- 4.1 — главное окно на DSL, паритет с текущей версией.
- 4.2 — окно настроек: список доменов, удаление записи, флаги.
- 4.3 — системная интеграция: регистрация обработчиком ссылок, иконка, реестр.

Панель служб:

- 4.4 — слой служб на Rust: `svc list --json`, старт/стоп/рестарт, хвост лога.
- 4.5 — окно на DSL: список, статусы, кнопки, «запустить все Manual».
- 4.6 — обновление по `every` и хвост лога выбранной службы.

Готово, когда:

- 4.7 — замеры: холодный старт, DPI, ошибки конфига; 1–2 недели ежедневного
  использования обеих версий.

## Открытые решения

| Вопрос                                     | Шаг      | Рекомендация            |
| ------------------------------------------ | -------- | ----------------------- |
| Кодеген: build.rs-генератор или proc-macro | 3.4      | офлайн-генератор первым |
| Скролл в настройках и панели служб         | 4.2, 4.5 | clip + wheel            |
| Права панели служб                         | 4.5      | elevated-манифест       |
| Многострочный текст лога                   | 4.6      | один `Text` + clip      |

## После MVP

- Зарезервированные метрики текста (union shaping): текст шейпится по самому
  широкому весу из состояний, поэтому `font-weight` не требует фиксированного
  размера `Text`. Сейчас он разрешён только на `Text` с заданными `width` и
  `height` ([style.md](../lang/style.md#текстовые-метрики)).
- Follow-режим хвоста лога, фильтр по логу, иконка панели служб в трее.
