## После MVP

- Зарезервированные метрики текста (union shaping): текст шейпится по самому
  широкому весу из состояний, поэтому `font-weight` не требует фиксированного
  размера `Text`. Сейчас он разрешён только на `Text` с заданными `width` и
  `height` ([style.md](../lang/style.md#текстовые-метрики)).
- Follow-режим хвоста лога, фильтр по логу, иконка панели служб в трее.
