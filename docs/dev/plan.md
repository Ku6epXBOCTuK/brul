# План

Маршрут срезами: один срез — один коммит и один ревью. Процесс и бюджет среза —
[workflow.md](workflow.md); здесь только очередь. Срез закрыт, когда зелёные
`cargo clippy --workspace -- -D warnings` и `cargo test --workspace`; закрытая
строка удаляется из файла, историю хранит git. Текущий срез — задача в трекере
`BRUL`.

## Фаза 3 — DSL

Выражения (3.1):

- 3.1.0 — крейт `brul-syntax`: SFC-сплиттер, `pest` и его тесты переезжают из
  `brul-compiler`, поведение не меняется.
- 3.1.1 — лексер: токены, позиции, пробелы, `//`, идентификаторы, числа.
- 3.1.2 — лексер: строки, шаблон-сырьё, операторы, ошибки лексера.
- 3.1.3 — вход парсера и литералы: `Number`/`String`/`Bool`/`Null`/`Ident`,
  `Eof`.
- 3.1.4 — постфикс: `.имя`, `[…]`, `(…)`.
- 3.1.5 — унарные и бинарные уровни `||`…`*`, левая ассоциативность.
- 3.1.6 — тернарник `?:` и присваивание `=`, `+=`, `-=`.
- 3.1.7 — массивы и объекты.
- 3.1.8 — шаблоны: `${}` с вложенными выражениями и позициями.

Разметка (3.2):

- 3.2.1 — AST разметки, `component`/`window`, пустой блок.
- 3.2.2 — `prop`/`event` с типами и значениями по умолчанию.
- 3.2.3 — элементы и вложенные блоки.
- 3.2.4 — аргументы: классы, `имя: Expr`, зарезервированный `on` и `HandlerRef`.
- 3.2.5 — `if`/`else`.
- 3.2.6 — `each`.
- 3.2.7 — листовые `Text`/`Image` (в блоке одно выражение).

Стили (3.3):

- 3.3.1 — лист стилей, пустые `.class { }`, позиции ошибок.

- 3.3.3 — цвета: `#rgb`, `#rrggbb`, `#rrggbbaa`, `transparent`, `white`.
- 3.3.4 — ссылки `theme.ключ` и блоки `theme Ident { … }`.
- 3.3.5 — `linear-gradient(...)`.
- 3.3.6 — шорткат `border: <px> <color>`.
- 3.3.7 — состояния `.class:state`.
- 3.3.8 — валидация свойств и значений по таблице MVP.
- 3.3.9 — состояния: только визуальные свойства, `font-weight` с размером.
- 3.3.10 — темы: одинаковый набор ключей и типов, дефолт — первая.
- 3.3.11 — снапшоты и merge классов слева направо.

## Фаза 4 — MVP

bropicker:

- 4.1 — главное окно на DSL, паритет с текущей версией.
- 4.2 — окно настроек: список доменов, удаление записи, флаги.
- 4.3 — системная интеграция: регистрация обработчиком ссылок, иконка, реестр.

Панель служб:

- 4.4 — слой служб на Rust: `svc list --json`, старт/стоп/рестарт, хвост лога.
- 4.5 — окно на DSL: список, статусы, кнопки, «запустить все Manual».
- 4.6 — обновление по `every` и хвост лога выбранной службы.

Готово, когда:

- 4.7 — замеры: холодный старт, DPI, ошибки конфига; 1–2 недели ежедневного
  использования обеих версий.

## После MVP

- Зарезервированные метрики текста (union shaping): текст шейпится по самому
  широкому весу из состояний, поэтому `font-weight` не требует фиксированного
  размера `Text`. Сейчас он разрешён только на `Text` с заданными `width` и
  `height` ([style.md](../lang/style.md#текстовые-метрики)).
- Follow-режим хвоста лога, фильтр по логу, иконка панели служб в трее.
