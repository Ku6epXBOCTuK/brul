# BRUL

Нативный UI на Rust: окно на winit/wgpu, виджеты, текст и реактивное ядро.

## Пример

```sh
cargo run -p hello
```

`examples/hello` — минимальный потребитель в рабочей копии: окно, хост-команда,
кнопки из кита. Разбор — в его [README](examples/hello/README.md).

Требования к фреймворку — [docs/dev/product.md](docs/dev/product.md), устройство
— [docs/dev/architecture.md](docs/dev/architecture.md).
