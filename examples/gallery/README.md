# Gallery

Живая галерея стандартных компонентов из `kit/`:

```sh
cargo run -p gallery
```

`T` переключает `dark`/`light`, `Esc` закрывает окно. Разметка окна не хранится
в репозитории: `build.rs` вызывает `brul::build::gallery()`, который собирает
секции из файлов `kit/*.brul` и их объявленных prop-ов. Новый компонент кита
попадает в галерею после пересборки без правки примера.
